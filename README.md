# HFVAE

This workspace contains local experiments for high-frequency robust VAE training on top of the bundled Wan2.2 VAE.

The `/media/home/lizhonghao/diff_pde` repository is treated as read-only reference/data. All new code, caches, checkpoints, and results live under this workspace.

## Files

- `hfvae/wan22_hf_vae.py`: Wan2.2 VAE wrapper with anti-aliasing, HFS, and spectral filtering.
- `hfvae/frequency.py`: Fourier filters and frequency-aware losses.
- `hfvae/ns_data.py`: read-only loader for NS shards generated by `diff_pde`.
- `experiments/train_hf_vae.py`: VAE training entry point.
- `experiments/eval_hf_vae.py`: reconstruction and band-error evaluation.
- `experiments/score_robust_vae.py`: fixed, side-effect-free autoresearch benchmark.
- `experiments/cache_vae_latents.py`: encode VAE embeddings into local latent caches.
- `experiments/train_latent_operator.py`: latent autoregressive tests for FNO, Transolver, and CNextU.
- `docs/high_frequency_robust_vae.md`: math notes and recommended commands.
